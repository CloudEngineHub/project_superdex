# FR3 v2 MJCF Test Asset

This directory contains the Franka FR3 v2 MJCF (`fr3v2.xml`) and the visual and collision meshes it references from [MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie), directory [`franka_fr3_v2`](https://github.com/google-deepmind/mujoco_menagerie/tree/62ab00f2bc44f6f20c1c9b7a13f3fb1dd41a4e35/franka_fr3_v2), commit `62ab00f2bc44f6f20c1c9b7a13f3fb1dd41a4e35`. The files are unmodified; the upstream `scene.xml`, `CHANGELOG.md`, `README.md`, preview image, and unreferenced meshes are omitted.
